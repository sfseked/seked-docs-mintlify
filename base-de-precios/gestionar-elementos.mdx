La base de precios de Seked está compuesta por elementos de distintos tipos que, combinados, te permiten construir presupuestos completos y coherentes. Saber crear, mantener y organizar bien esos elementos es la clave para que todo el equipo gane velocidad y precise menos correcciones. En esta guía encontrarás todo lo que necesitas para gestionar el catálogo de tu empresa.

## Tipos de elementos

La base de precios se organiza en tres menús:

<CardGroup cols={3}>
  <Card title="Partidas" icon="list-check">
    Los conjuntos listos para presupuestar que ya has trabajado alguna vez: el descompuesto completo de una unidad de obra, propia o subcontratada.
  </Card>

  <Card title="Materiales" icon="boxes-stacked">
    La unidad mínima de la base de precios. El descompuesto de una partida es un sumatorio de materiales.
  </Card>

  <Card title="Mano de obra" icon="helmet-safety">
    El listado de oficios de tu empresa, cada uno asociado a su rendimiento.
  </Card>
</CardGroup>

### Campos de una partida

| Campo | Descripción |
| --- | --- |
| **Partida** | Descripción de la unidad de obra. |
| **Tipo** | Si el precio corresponde a un descompuesto propio (materiales) o a una subcontrata. |
| **Capítulo** | Sección o categoría a la que pertenece según la clasificación de tu empresa. |
| **Precio base** | Coste unitario de referencia. |
| **Rendimiento** | Unidades de obra que se ejecutan por unidad de tiempo o de recurso. |
| **Confianza** | Nivel de fiabilidad del precio, según cuántas veces se ha validado y su antigüedad. |
| **Precio de referencia** | Precio equivalente en bancos de precios externos (BEDEC, CYPE...) para contraste. |
| **Histórico** | Evolución del precio de la partida a lo largo del tiempo. |
| **Veces usada** | Número de veces que se ha utilizado esta partida. |
| **Aprendizajes** | Notas o ajustes acumulados de usos anteriores. |
| **Última vez usada** | Fecha del uso más reciente. |
| **Estado** | Situación de la partida (por ejemplo, validada o pendiente de revisión). |
| **Comentarios** | Anotaciones libres del equipo. |

### Campos de un material

| Campo | Descripción |
| --- | --- |
| **Material** | Descripción del producto o suministro. |
| **Capítulo** | Categoría a la que pertenece. |
| **Precio base** | Coste unitario de referencia. |
| **Precio de referencia** | Precio equivalente en bancos de precios externos. |
| **Evidencia** | Documento (factura, albarán, oferta) que respalda el precio. |
| **Veces usado** | Número de veces que se ha utilizado este material. |
| **Última vez usado** | Fecha del uso más reciente. |
| **Estado** | Situación del material (por ejemplo, validado o pendiente de revisión). |
| **Comentarios** | Anotaciones libres del equipo. |

### Campos de mano de obra

| Campo | Descripción |
| --- | --- |
| **Oficio** | Categoría laboral (oficial, peón, encargado...). |
| **Precio base** | Tarifa de referencia asociada al oficio. |
| **Veces usado** | Número de partidas en las que se ha utilizado este oficio. |
| **Última vez** | Fecha del uso más reciente. |
| **Estado** | Situación del oficio (por ejemplo, validado o pendiente de revisión). |
| **Comentarios** | Anotaciones libres del equipo. |

## Crear un nuevo elemento

<Steps>
  <Step title="Accede a la base de precios">
    En el menú lateral, haz clic en **Base de precios**. Verás el listado general de todos los elementos del catálogo de tu empresa.
  </Step>
  <Step title="Selecciona 'Subir documento'">
    Haz clic en **Subir documento** para importar los elementos a partir de un archivo existente.
  </Step>
  <Step title="Añade el documento">
    Sube el archivo del que quieres extraer los elementos: **Excel**, **PDF**, **Word**, **DWG**, **DXF**, **factura**, **albarán**, etc. Seked analizará el contenido automáticamente.
  </Step>
  <Step title="Valida la asociación de campos">
    Seked te mostrará un menú con las asociaciones que ha detectado entre los datos del documento y los campos de la base de precios. Por ejemplo: _Proveedor → Cementos Molins_. Revisa cada asociación y confirma que los campos se están vinculando correctamente antes de continuar.
  </Step>
  <Step title="Guarda los elementos">
    Una vez validadas las asociaciones, haz clic en **Guardar**. Los elementos quedarán disponibles de inmediato para todo el equipo con acceso a la base de precios.
  </Step>
</Steps>

<Tip>
  Cuantos más datos incluya la documentación que subas (ubicación, proveedor, fecha, referencia, unidades, etc.), mejor será la asociación de partidas y más precisos los datos que Seked pueda generar automáticamente.
</Tip>

## Editar un elemento existente

<Steps>
  <Step title="Localiza el elemento">
    Usa el buscador o los filtros (capítulo para partidas y materiales, oficio para mano de obra) para encontrar el elemento que quieres modificar.
  </Step>
  <Step title="Abre el detalle">
    Haz clic sobre el nombre del elemento para abrir su ficha completa.
  </Step>
  <Step title="Edita los campos necesarios">
    Haz clic en **Editar** (icono de lápiz) en la parte superior derecha de la ficha. Modifica los campos que necesites.
  </Step>
  <Step title="Guarda los cambios">
    Haz clic en **Guardar cambios**. Seked te preguntará si deseas propagar la actualización de precio a los proyectos activos que usen este elemento.
  </Step>
</Steps>

<Note>
  Los cambios de precio no se aplican retroactivamente a proyectos cerrados o archivados; solo a los que están en estado _Activo_ o _En revisión_.
</Note>

<Note>
  Si dos personas editan el mismo precio a la vez, no se sobrescriben entre sí: cada edición se guarda como una evidencia de precio independiente, ya que aunque sea la misma partida, cada persona puede estar aportando información distinta (una cantidad, una ubicación o un proveedor diferente).
</Note>

## Organizar elementos en la base de precios

La base de precios agrupa los elementos según su naturaleza y cada bloque se organiza con su propia jerarquía:

- **Partidas**: organizadas por **capítulo** (p. ej., _Estructura_, _Instalaciones_, _Acabados_). Cada partida se compone del sumatorio de sus **materiales** y lleva asociado un **oficio de mano de obra** a través de su rendimiento.
- **Materiales**: organizados por **capítulo**, con su precio base y su precio de referencia. Al ser la unidad mínima, cualquier cambio en un material se refleja en todas las partidas que lo incluyen.
- **Mano de obra**: contiene todos los **oficios** (oficial, peón, encargado, ferrallista, fontanero, pintor, etc.) con su tarifa correspondiente.

## Buscar y filtrar elementos

Desde el panel principal de la base de precios dispones de varias herramientas de búsqueda:

- **Buscador de texto libre**: busca por nombre, código o cualquier palabra en la descripción.
- **Filtro por tipo**: filtra solo materiales, partidas o mano de obra.
- **Filtro por capítulo (partidas y materiales) u oficio (mano de obra)**: navega por la jerarquía de clasificación del bloque correspondiente.
- **Filtro por etiqueta**: encuentra todos los elementos con una misma etiqueta.

<Tip>
  Combina el filtro de capítulo con el buscador de texto para encontrar un elemento concreto dentro de un capítulo extenso. Por ejemplo, filtra materiales por el capítulo _Instalaciones_ y busca «tubo cobre» para ver solo las referencias de ese producto.
</Tip>
